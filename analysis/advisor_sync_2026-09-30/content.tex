\slide{Quick recap: what HetNet gives us}
{\begin{itemize}
\item Heterogeneous teams: sensing agents and capture/extinguish agents have different physical abilities.
\item Class-indexed communication transforms, typed relations and class-specific action outputs.
\item A training-only state embedding node supplies class-value predictions on the exercised path.
\item The binary variant sends one 16-bit payload per agent per round; two rounds per step.
\end{itemize}
\point{Our starting point: keep the domains and communication setting, remove explicit class selectors from the actor.}
\small The current reproduction runs use \textbf{HetNet Real}; the 32-bit comparison describes HetNet Binary.}
{Keep this to roughly a minute. The paper calls its formulation MAH-POMDP. Do not call the state embedding node the simulator's complete global state: it combines metadata and agent features. In the released preprocessing, some recurrence is shared and the sensing branch is specific to sensing agents, so ``a completely separate network per class'' is too broad. The original Real runs are a contextual reference, not an information- and optimizer-matched baseline.}
{Seraj et al., AAMAS 2022, Secs. 4--5; \code{hetgat/uavnet.py}; \code{hetgat/graph/fastbinary.py}; recorded reproduction configurations.}

\slide{Where this sits relative to Howell et al.}
{\begin{itemize}
\item Capability-aware shared policies and learned communication already have a direct precedent: Howell et al., CoRL 2023.
\item Our shared model is close in its core idea. The implementation adds recurrent history, binary payloads and receiver-dependent attention in HetNet's domains.
\item Banked asks a narrower question: do capability/history-dependent communication transforms help beyond that shared baseline?
\item CASH is also relevant prior work on capability-conditioned parameter generation.
\end{itemize}
\point{The contribution has to come from the controlled question and evidence. Banks are a hypothesis.}}

The fixed binary channel and intervention protocol make a concrete study, but architectural differences alone do not establish novelty or usefulness. If shared wins, the result should stay in the story. Do not call this the first class-free policy or claim that capability-aware parameter generation is new.}

\slide{What each agent is allowed to know}
{\[
\kappa_{j,t}=(s_{j,t},a_j):\qquad (1,0)\text{ sensing},\quad (0,1)\text{ actuating},\quad (0,0)\text{ after sensing loss}.
\]
\[
x_{j,t}=[\text{position encoding};\ s_{j,t}(\text{outside},\text{target},n_P+n_A);\ \kappa_{j,t}].
\]
\begin{itemize}
\item Merge \emph{per-cell counts}, not Boolean occupancy; no neighbor type labels or agent IDs.
\item PCP: $25(25+3)+2=702$ inputs. One six-action head; impossible actuation has probability zero.
\item Own sensor health is known. Loss preserves localization, memory, movement and radio.
\end{itemize}
\small On nominal training data, the two capability vectors still identify physical class.}
{This is removal of explicit labels and class-indexed actor weights, not statistical independence from class. The failure study introduces the new capability value (0,0). Each agent gets its own capability flags, not an oracle list of everybody's capabilities. SoftRole uses corrected independent observation copies; original reproduction defaults remain legacy. Relative to a corrected typed observation, merging channels discards information. That does not mean every buggy legacy observation is richer than every corrected new observation.}

\item PCP: encoder $702\to128$, LSTM $150\to64$, communicated output width 16.

\slide{Shared vs banked: the actual difference}
{\[
g_{j,t}=\softmax\!\left(G([H_{j,t};\kappa_{j,t}])\right),\qquad G:66\to32\to4.
\]
\[
B(x,g)=\sum_{k=1}^{K}g_k(W_kx+b_k),\qquad g_k\ge0,\quad\sum_k g_k=1.
\]
\begin{itemize}
\item \textbf{Shared:} one effective transform, no gate network; 171,087 PCP parameters.
\item \textbf{Banked:} four experts; 224,171 PCP parameters. Same observations, learner and message budget.
\item Identical experts recover the shared map exactly. Extra capacity does not guarantee easier training.
\end{itemize}
\small $\|\sum_k g_kW_k\|\le\max_k\|W_k\|$ bounds mixing relative to the experts, not the whole recurrent system.}
{The bank is the additional hypothesis. Sender encoders use the sender's gate; decoding and attention use the receiver's gate. The equality with a shared transform follows immediately when every expert has the same matrix and bias. Do not say this reproduces all of original HetNet: the inputs, relation structure and attention differ. A finite softmax also does not produce an exact one-hot gate. The norm inequality says nothing about whether experts grow large or whether optimization converges.}
{\code{softrole/model.py:AffineBank,HeadBank,CommunicationRound}; parameter counts in recorded runs; triangle inequality.}

\slide{What goes over the wire}
{\[
u_k=B_{\rm enc}(h_k,g_k),\qquad b_k=\mathbf1[u_k+\nu_k>0],\quad \nu_k\sim\mathrm{Logistic}(0,1)^{16}.
\]
\[
m_{jk}=B_{\rm dec}(b_k,g_j),\qquad
\bar m_j=\sum_{k\in\mathcal N(j)}\alpha_{jk}m_{jk}.
\]
\begin{itemize}
\item $\Pr(b_{k,d}=1\mid u_{k,d})=\sigma(u_{k,d})$; fresh noise for each bit and round.
\item Receiver-dependent GATv2 attention normalizes over permitted senders \emph{plus null}.
\item Null contributes zero. No neighbors means exactly zero received aggregate.
\item Two 16-bit broadcasts: \textbf{32 payload bits per agent-step}, shared across receivers and heads.
\end{itemize}
\small Training uses a biased straight-through sigmoid derivative.}
{The receiver sees the binary payload, not the sender's uncompressed hidden state. The first round concatenates four heads with ReLU; the second averages the heads without a final nonlinearity. The Logistic CDF proves the Bernoulli marginal, but not an unbiased gradient estimator. The payload total excludes network headers and delivery overhead. GATv2 motivates receiver-dependent ranking; it does not guarantee higher return. We omit the old guide's specific toy-gradient ratios because they are not a result about these trained policies.}
{\code{softrole/model.py:straight_through_bits,CommunicationRound}; \refpaper{https://arxiv.org/abs/2105.14491}{Brody et al., GATv2, ICLR 2022}.}

\slide{Training against the team objective}
{\[
J(\theta)=\E\!\left[\sum_{t=0}^{\tau-1}\sum_{j=1}^{N}r_{j,t}\right],\qquad \gamma=1,\quad\tau\le T.
\]
\begin{itemize}
\item One pooled team critic; every agent's action score uses the same team GAE advantage.
\item Sum episode gradients across collectors; average once by the global episode count; clip once at 0.75.
\item RMSprop: learning rate $10^{-4}$, $\alpha=0.97$, $\epsilon=10^{-6}$.
\item Actor coefficient 50, value coefficient 1, GAE $\lambda=0.95$; detach recurrence every five steps.
\end{itemize}
\point{This is a practical approximate learner, not an unbiased-estimator or convergence claim.}}
{Team credit matches the intended reward sum: an action that helps another agent should receive credit. The critic is permutation-invariant through mean pooling plus team metadata. Approximation sources are the learned critic inside GAE, straight-through bits, and truncated backpropagation. The original and new pipelines have different loss normalization, so raw critic losses should not be compared directly. Avoid the old guide's broad claim that the released optimizer is effectively SGD; this update does not establish it.}
{\code{softrole/learning.py}; \code{softrole/train.py:apply_gradients}; \code{softrole/rollout.py}; \refpaper{https://arxiv.org/abs/1506.02438}{Schulman et al., GAE}.}

\slide{Backup: math behind the checks}
{\small
\textbf{Team GAE and actual episode loss} ($V_\tau=0$, stop-gradient $\sg$):
\[
\delta_t=r_t+V_{t+1}-V_t,\quad \widehat A_t=\delta_t+0.95\widehat A_{t+1},\quad
\widehat R_t=\sg(\widehat A_t+V_t),
\]
\[
L_e=-50\sum_t\left(\sum_j\log\pi_\theta(a_{j,t}\mid\text{local history and messages})\right)\sg(\widehat A_t)
+\frac1{\tau_e}\sum_t(V_t-\widehat R_t)^2.
\]
\textbf{Why team credit matters:} if $a_1\sim\mathrm{Bernoulli}(\sigma(\theta))$, $r_1=0$, $r_2=a_1$,
\[
\E[\nabla_\theta\log\pi(a_1)r_1]=0,\qquad
\nabla_\theta\E[r_1+r_2]=\sigma(\theta)(1-\sigma(\theta))>0.
\]
\textbf{What attention guarantees:}
\[
\left\|\sum_k\alpha_{jk}m_{jk}\right\|\le(1-\alpha_{j\varnothing})\max_k\|m_{jk}\|.
\]
Empty neighborhoods give zero. This does not measure causal communication value.}
{The two-agent example is an exact counterexample to own-return credit for a team objective. It is not a proof that every production gradient is unbiased. Communication uses straight-through derivatives, GAE uses an approximate critic, and recurrence is truncated. The attention bound follows from nonnegative normalized weights and the triangle inequality; it requires a nonempty neighborhood for the maximum expression. Permuting agent order leaves pooled critic outputs unchanged and permutes actor outputs when states, adjacency and random draws are permuted consistently; that symmetry does not prove generalization.}
{\code{softrole/learning.py}; SoftRole learning and model tests; equations checked against current source.}
