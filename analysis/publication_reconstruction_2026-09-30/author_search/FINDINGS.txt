Useful positive finding: exact FireCommander ancestry

EsiSeraj/FireCommander2020 is explicitly linked by the HetNet README as the
source domain. Its public history starts July 2020, but the last 2020 tree
(176a6b1, November 4) contains documentation placeholders rather than the
Python MARL implementation. Full MARL source appears at:

  b04e8ec702f5c550978a170d9823c2a39de617be — October 28, 2021

Its MARL Package/WildFire_Model.py is byte-for-byte identical to HetNet's
WildFire_Simulate_Original.py first bundled at 59d5983 in February 2022:

  13,934 bytes
  SHA256 825001e5a5d274e6396bc902576760a1fda838268ad6e2d4be1a6c02bf520b04

This is positive lineage evidence, not a recovered bug-free dependency. The
same strict x>0/y>0 boundary predicate and untrimmed zero-filled output rows
exist in this older author repository. An unchanged-method probe sends a fire
at (0,2) and receives the fabricated zero row [0,0,0]. Substituting this older
module into HetNet therefore does not solve the phantom-front problem.

The original complex FireCommander wrapper builds hotspot rectangles using
center +/- 5. Those are nondegenerate and work with randint(low, high). HetNet's
5x5 adaptation instead uses [x,x,y,y], explaining why that bundled combination
fails on reset. The unchanged predecessor module successfully initializes a
nondegenerate rectangle and raises ValueError on equal bounds. This supports a
specific integration mismatch; it does not establish what unpublished wrapper
the authors actually trained.

Discovery before suppression is documented in executable predecessor code:

- Base utilities filter the fire map to state 2 (discovered fire) before pruning.
  A direct probe at the same cell leaves an undiscovered fire active, then
  removes it when marked discovered.
- Complex utilities require the suppression region to contain a sensed front.
  This is a region-level rule, not necessarily individual-cell discovery.

This independently supports discovery before extinguishing as domain intent.
It does not establish that the AAMAS wrapper enforced it. The Base environment
also has different default size/team/reward mixing and no identical growing-fire
protocol; the complex variants contain altitude/region mechanics. Copying one
of those whole environments would change the benchmark rather than restore a
verified AAMAS experiment. The reconstruction should expose its own version and
record which mechanics are historical, paper-derived, or explicitly repaired.

A read-only request redirects to Georgia Tech's GitHub LDAP sign-in. HTTP 200
is the sign-in page, not recovered repository contents. Nothing behind that
boundary was inspected. This institutional breadcrumb is a possible source
location, not proof that AAMAS experiment files are stored there.

Implications for training budgets

This author-account search supplies no new collector count, batch count or
actual training-step evidence. It therefore does not promote the June 2022
single-collector 10M-step floor into a known publication budget. Epochs depend
on collector count and episode overshoot; the previous audit's 10M versus 40M
uncertainty remains. More samples alone does not prove overfitting or harmful
training. Keep fixed-budget checkpoints and compare frozen performance on a
predeclared common evaluation panel; distinguish sample efficiency from final
performance. Do not infer an optimal stopping point from unmatched paper means.

Reproducibility and limitations

collect_public.py archives 32 public resources and fetch_manifest.json records
URLs, response timestamps, final redirects and SHA256s. API list pagination and
recursive tree truncation are checked. probe_evidence.py verifies those hashes,
compares exact predecessor/bundled module bytes through the existing audit Git
mirror and executes only the unchanged predecessor class methods described
above. evidence_checks.json contains all outcomes and repository/tree inventories.
Run from the workspace root:

  .venv/bin/python analysis/publication_reconstruction_2026-09-30/author_search/probe_evidence.py

The mutable owner inventories and website pages are a dated snapshot. Archived
immutable October 2021 source URLs can be fetched independently. No runtime,
training configuration, checkpoint, prior analysis or running job was modified.
